# Security Policy

## Supported Versions

ClearCut is currently under active development. Security updates are applied to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy issue in ClearCut, please do not report it through a public GitHub issue.

Instead, please report security vulnerabilities responsibly to the project maintainers via email or private vulnerability reporting.

Please include:
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue (proof-of-concept scripts or API payloads).
* Any affected components or boundary scopes (`org_id`, `project_id`, token handling, etc.).

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a responsible resolution.
