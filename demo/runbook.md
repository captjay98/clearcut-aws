# ClearCut Submission Demo Runbook

This is a conditional recording checklist for a video of at most three minutes. **Live provider proof is not currently available**, so the provider scene and final submission recording remain blocked. Never replace missing external evidence with the E2E fixture or seeded demo data.

## Preflight hard gates

1. Record the clean candidate SHA, verify target-remote parity, and bind all three deployed image digests to that SHA.
2. Verify the hosted site, web, and API candidate revisions before promotion.
3. Retain live Gemini and Parallel Search request/trace identities for the exact candidate. Record Extract only if it ran.
4. Confirm the entrant-owned screenplay disclosure, legal boundary, test/demo labels, and authorized demo accounts.
5. Confirm public-video visibility, English narration or subtitles, and a final duration no greater than 180 seconds.
6. Do not record this scene or publish the submission while any required gate remains NO-GO.

## Scene flow

1. **0:00–0:25 — Import and boundary:** Import `demo/original-screenplay/the_last_reel.fountain`. State that ClearCut supports evidence gathering and qualified human review, not legal advice or final legal clearance.
2. **0:25–1:05 — Live detection and research:** Show exact Gemini detection and mandatory Parallel Search identities, then attributable source snapshots. Show bounded Extract only when its real request identity is retained. If credentials or proof are missing, show the unresolved state and stop the submission recording.
3. **1:05–1:35 — Evidence workspace:** Compare cited, conflicting, and zero-evidence states. Show that missing evidence remains unresolved.
4. **1:35–2:10 — Governed rewrite:** Use separate authorized actors to propose and review a bounded rewrite; show the persisted audit result.
5. **2:10–2:35 — Selective re-evaluation:** Change a passage and show only behavior actually observed for that revision. Do not claim a fixed number of unaffected items or a savings percentage without measured proof.
6. **2:35–3:00 — Report release:** Generate an immutable report snapshot, complete the human attestation, release the frozen snapshot without regeneration, and download the stored HTML artifact.

Parallel Monitor is `not-enabled`. It may be added to the recording only after a human GO decision and deployed signed-webhook/re-verification proof are recorded in `docs/submission/manifest.yaml`.
