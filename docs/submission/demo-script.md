# ClearCut Conditional Three-Minute Demo Script

Use this script only after every live/deployed claim has evidence tied to the exact candidate revision. If a required proof is missing, say so and show the unresolved state rather than substituting synthetic data.

- **0:00–0:25 — Boundary and import:** Introduce the entrant-owned `the_last_reel.fountain` screenplay. State that ClearCut supports pre-clearance evidence work and does not provide legal advice or final legal clearance.
- **0:25–1:05 — Detection and provider evidence:** Show the exact deployed Gemini detection run and mandatory Parallel Search receipt. Show bounded Extract only if it ran. Display request identities and source provenance; do not present demo fixtures as provider output.
- **1:05–1:35 — Evidence and uncertainty:** Open one cited item and one unresolved or conflicting item. Show publisher/authority, retrieval time, excerpt, stance, and why zero evidence is not clearance.
- **1:35–2:10 — Human governance:** Have one authorized user propose a rewrite and a different authorized reviewer approve or reject it. Show that the action is persisted and audited.
- **2:10–2:35 — Revision lineage:** Modify a bounded passage and show the actual selective re-evaluation result. Do not state a savings percentage unless measured evidence is available.
- **2:35–3:00 — Clearance report:** Generate a frozen report snapshot, show the exact release confirmation and human attestation, release without regenerating, and download the stored deterministic HTML artifact.

Parallel Monitor may appear only if `manifest.yaml` records GO and the exact deployment has signed-webhook delivery and re-verification proof. Otherwise say that Monitor is not enabled.
