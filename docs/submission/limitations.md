# ClearCut Scope and Known Boundaries

1. **Pre-clearance framing:** ClearCut is an evidence workspace and workflow coordination tool. It does not provide legal advice or final legal clearance.
2. **Evidence provenance:** An evidence claim requires a cited source snapshot and attributable provenance. A detected item may exist with zero claims while research is pending, unavailable, failed, or empty; that state is unresolved, never clearance.
3. **No fallback evidence:** Missing credentials, provider errors, and zero-result searches create visible review work. Synthetic E2E/demo fixtures are labelled and are not Gemini or Parallel receipts.
4. **Human governance:** Evidence decisions, rewrite approvals, referrals, dispositions, report generation, and release/export require accountable authorized human triggers. Protected policy and legal-boundary rules are human-only.
5. **Local report format:** The implemented immutable artifact is deterministic HTML. Deterministic PDF, Cloud Storage delivery, and Cloud Tasks production proof are not available and are not claimed.
6. **Provider proof:** No live Gemini, Parallel Search, or Parallel Extract trace tied to an exact deployed candidate is currently recorded. Parallel Monitor is not enabled.
7. **Cloud readiness:** Terraform is scaffolding, the current Docker image is a combined local validation runtime, and no authorized GCP apply, three-image digest set, hosted revision, backup/PITR restore, rollback, rotation, observability, redaction, or budget-alert proof is recorded.
8. **Revision provenance:** The active candidate contains intentionally preserved uncommitted work, so a clean SHA and target-remote parity cannot yet be asserted.
9. **Submission media:** No verified public video URL, duration, visibility, subtitles, or Devpost submission confirmation is recorded.
10. **Compliance correspondence:** Written organizer clarification about development-assistant eligibility remains pending.
